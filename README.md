# NovaOS

> The Future of Personal Computing

NovaOS is a futuristic desktop environment built in Python using CustomTkinter.

## Features

- Modern Desktop
- Glassmorphism UI
- Taskbar
- Start Menu
- Window Manager
- File Manager
- Browser
- AI Assistant
- Settings
- Music Player

## Tech Stack

- Python
- CustomTkinter
- Pillow
- SQLite
- psutil
